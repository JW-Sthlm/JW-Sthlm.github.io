Privacy notice

This notice covers Longevist's Oura connection and these public information pages.

When you authorize Oura access, Longevist requests daily wellness summaries and sleep data. It also requests heart-rate data, workouts and sessions, SpO2, stress and basic Oura profile information. The purpose is to answer the account owner's wellness and training questions.

When enabled, the connection sends requested data through an Azure-hosted backend to ChatGPT. Auth0 handles sign-in to the private integration, not the Oura health data. Each provider's terms and privacy rules also apply.

OAuth credentials are kept in private configuration and token storage, never in this public website. Longevist does not sell Oura data or use it to train AI models.

The Oura connection is intended for on-demand reads rather than a separate health-history database. ChatGPT conversations and user-created exports may retain the results. You can revoke Oura access and remove the ChatGPT connection. That does not automatically delete previous conversations or exports; delete those separately.

GitHub Pages hosts these information pages. They do not ask for Oura credentials or collect health data. GitHub may process technical access logs under its own privacy statement.

This is a single-user personal project. Use the contact email provided in the Oura application details for questions. Do not send health records or credentials through public GitHub issues.
