# Product

## Register

brand

## Users

Partner consultants, solution architects, AI practitioners, workshop participants, and curious non-developers arriving from LinkedIn or a shared link. They want to find something useful quickly, understand whether it is ready to use, and reach the source without navigating an unfiltered GitHub profile.

## Product Purpose

Create a clear public front door for Johan Wallquist's reusable AI, agent, partner, and Copilot CLI work. Success means visitors can identify the right asset in under a minute, distinguish reusable work from reference material, and open either a working demo or the source repository.

## Brand Personality

Practical, opinionated, generous.

The page should feel like an experienced architect opening his own toolbox, not a personal-brand portfolio or a software company landing page.

## Anti-references

- Generic developer portfolios with skill meters, technology-logo walls, and employment timelines.
- A raw mirror of every public repository.
- AI-themed landing pages with neon gradients, glowing brains, or vague claims.
- Microsoft corporate styling that could imply these are official Microsoft products.
- Calling every public repository open source when no reuse license exists.

## Design Principles

1. Lead with what someone can use, not with Johan's biography.
2. Curate aggressively. A smaller useful collection beats a complete inventory.
3. Show the boundary between licensed assets, source-available references, and live demos.
4. Keep GitHub visible as the source of truth.
5. Sound like a practitioner sharing working material with peers.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard navigation, visible focus states, reduced motion, high text contrast, semantic landmarks, useful alt text, and responsive layouts from small mobile screens through large desktops.
