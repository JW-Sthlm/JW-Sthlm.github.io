Field notes

Where this work actually runs

Agent tools change names often. Here is what the three I use are, without jargon, so you can tell which one you are looking at.

Copilot Cowork

A shared workspace where you hand a task to an agent and it works on documents with you. You can upload a skill file so it follows your way of doing things.

Microsoft Scout

An agent that picks up skills from a folder you point it at. Good when you want the same instructions available every time, without setting them up again per task.

Copilot CLI

The agent in a terminal window, sitting next to your files. Most of what you see on this page was built here, because the agent can read the project and run things itself.

What a skill is

A plain text file that tells the agent how you want something done. The file itself moves between all three. Scripts and connections usually need small edits per tool.
